# SIRGEO — distribuição dos plugins

Índices de versão e pacotes de instalação dos plugins da suíte SIRGEO.

- Cada produto tem sua pasta (`shapebuilder/`, …) com o índice lido pelo gerenciador de complementos do QGIS
  (`plugins.xml`) e o índice assinado lido pelo próprio plugin (`releases.json`).
- Os instaladores são anexos dos releases, um por versão.

O uso dos plugins depende de licença por máquina.
